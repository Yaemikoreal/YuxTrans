## 关于 YuxTrans

YuxTrans 是一个**纯浏览器扩展**，不依赖任何后端服务。Service Worker 直接连接本地 Ollama 或云端 API，在网页边缘完成翻译，再把结果以页边批注的形式落回原文一侧。

它不为功能密度而生，只回应一个问题：在长篇阅读里，翻译如何尽量不打断思路。围绕这个问题，它只做三件事，并努力把它们做安静——

- **本地优先**：原生支持 Ollama，敏感文本不出本机，离线亦可阅读。
- **稳态可依**：本地模型不可用或云端限流时，自动切换备用供应商；默认 200MB IndexedDB 缓存，命中即毫秒返回。
- **档案式管理**：设置页保存多组「供应商档案」（Provider、凭据、模型），popup 中一键切换。

当前稳定版为 **v0.6.0**。

## 设计取向（UI v2.1）

一句话：**书房衬纸的皮，Apple 的骨。**

- **皮是纸墨**：墨韵为骨，暖纸为底，暮瞳作微光。拒绝纯黑纯白、高饱和科技色与弹跳动效；加载态是未写完的省略号，而非旋转的环。
- **骨是秩序**：借鉴 Apple HIG 的组件骨架——分组卡片即信息层级、「标签左 / 值右」的扫读动线、0.5px 分隔线、一屏唯一实心主动作。Popup 与设置页由此获得清晰的落点，而非一片均匀的灰。
- **为眼睛校准的三级文字**：主文本墨韵（13:1）/ 译文 `#4A453F`（8.6:1，AAA）/ 标签 `#6B655C`（5.1:1，AA），批注灰只留给出占位与装饰。长读不累，层次仍在。
- **长在页面里，又不碰页面**：全部悬浮 UI（划词浮窗、操作条、控制条等）运行在 Shadow DOM 中，样式与宿主页面严格隔离。

## 三种整页双语呈现

深阅读与快速扫读是两种正当的需求，YuxTrans 不做取舍，给三种模式：

- **段落对照**（新增）：译文整段跟随在原文段落之后，原文排版一字不动——连续读完原文，再读译文，视线不跳跃。鼠标悬停译文段，暮瞳微光铺满整段。
- **行内注脚**：译文以暮瞳竖线标注、紧跟句后，适合边读边对照。
- **仅译文**：整页替换为译文，效率优先，可一键恢复原文。

在「设置 → 交互与显示 → 双语呈现方式」中选择，整页控制条上也可随时切换双语 / 仅译文。

## 安装

1. 在 [Releases](https://github.com/Yaemikoreal/YuxTrans/releases) 下载最新 `YuxTrans-extension-v*.zip` 并解压；或克隆本仓库。
2. 打开 Chrome / Edge，访问 `chrome://extensions/` 或 `edge://extensions/`。
3. 开启右上角「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择 **`extension/`** 目录（需含 `manifest.json`）。
5. 工具栏出现图标后即可使用。

## 配置

点击扩展图标 →「设置」：

| 模块 | 做什么 |
| :--- | :--- |
| **服务档案** | 选择本地 Ollama / 云端供应商 / 自定义 OpenAI 兼容端点；保存并启用档案。 |
| **翻译偏好** | 语言方向、翻译风格、风格提示词、离线模式。 |
| **交互与显示** | 划词触发方式、流式输出、双语呈现方式（行内注脚 / 段落对照）、悬停/词典、原文样式等。 |
| **数据与存储** | 术语表、缓存限额、导入导出、网站规则。 |
| **诊断排障** | 用量与请求日志（只读）。 |

| 类型 | 操作 |
| :--- | :--- |
| 本地 Ollama | Provider 选 `local`，填写模型名（如 `qwen3.5:0.8b`），确保 Ollama 已启动。 |
| 云端供应商 | 选 `qwen` / `openai` / `deepseek` / `anthropic` / `groq` / `moonshot` / `siliconflow` / `google`（免 Key）等，填写 API Key 与模型。 |
| 自定义供应商 | 选 `custom`，填写端点、API Key、API 格式与模型。 |

各模块底部有独立「保存」按钮，改哪页存哪页。API Key 与配置仅保存在浏览器本地。

## 用法

### 划词翻译

- 默认「修饰键 + 划选」：按住 **Ctrl**（可在设置中改为 Alt/Shift）划选文本松开后翻译；若想选中即译，在「交互与显示」中改为「选中后弹出」。
- 快捷键 `Alt + T`（macOS 同 `Alt + T`）。
- 右键选中文本 →「翻译选中内容」。

### 悬停段落翻译

- 在「交互与显示」中开启「悬停段落翻译」。
- 按住 **Alt**（或你设置的修饰键），鼠标悬停在段落上约 300ms，段落后出现译文便签。

### 单词词典

- 开启「单词词典模式」后，划到或双击单词可弹出释义卡片（音标、义项、例句）。

### 整页翻译

- Popup 主按钮「翻译整页」。
- 快捷键 `Alt + P`（macOS 同 `Alt + P`）。
- 页面空白处右键 →「翻译整页」。

可视区域优先、支持流式边译边显与取消；双语呈现可选「行内注脚」或「段落对照」（设置 → 交互与显示），控制条可切换双语 / 仅译文或恢复原文。

### 快捷键

| 快捷键 | 功能 |
| :--- | :--- |
| `Alt + T` | 翻译选中内容 |
| `Alt + P` | 翻译整页 |
| `Ctrl`（可改）+ 划选 | 划词翻译（默认触发模式） |
| `Alt`（可改）+ 悬停 | 段落翻译（需在设置中开启） |

> **提示**：若快捷键不生效（被浏览器或其他扩展占用），可在 `chrome://extensions/shortcuts` 中自定义。
